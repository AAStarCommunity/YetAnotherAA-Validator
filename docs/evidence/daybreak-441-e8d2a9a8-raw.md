2. **Medium** — [DeployOverIssueVerifier.s.sol:195](/Users/jason/Dev/aastar/dvt-wt/v441-try/contracts/script/DeployOverIssueVerifier.s.sol:195)  
   **Failure scenario:** A nonzero `EXPECTED_AGGREGATOR` takes precedence over `CANONICAL_AGGREGATOR`. Even after the canonical constant is populated, a stale or malicious environment value can replace the pin with any look-alike contract. That contract can spoof all probes and `version()`, causing deployment of a verifier bound to the wrong aggregator; handing it to the real aggregator makes every proof fail.  
   **Suggested fix:** When `CANONICAL_AGGREGATOR` is nonzero, require both `AGGREGATOR` and any supplied `EXPECTED_AGGREGATOR` to equal it. Use the environment value only while the compiled canonical pin is zero.
